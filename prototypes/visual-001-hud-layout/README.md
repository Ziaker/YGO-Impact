# VIS-001 — HUD principal

**Decisão vigente:** **versão melhorada aprovada pelo autor em 2026-09-29**.

Este diretório contém o protótipo estático comparável A/B/C originalmente versionado para composição do mapa e HUD.

Abra `index.html` em navegador moderno. Não há dependências, build ou rede obrigatória.

Este experimento testa **aparência, hierarquia e densidade**. Não valida movimento, timing, Correntes interativas, Fog of War dinâmico ou outras regras temporais; esses itens exigirão protótipos executáveis específicos antes da implementação final.

O `index.html` atual deve ser preservado como **comparador histórico A/B/C**. O registro disponível no Git não sustenta afirmar que a revisão melhorada aprovada corresponde exatamente a A, B ou C pura. Não usar a ausência de um snapshot executável separado da revisão melhorada para rebaixar a decisão a “aguardando aprovação”: a aprovação explícita do autor prevalece.

Documento normativo do experimento: `docs/prototypes/VIS-001-hud-layout.md`.
