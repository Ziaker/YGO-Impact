# VIS-001 — HUD principal

Protótipo estático comparável A/B/C para composição do mapa e HUD.

Abra `index.html` em navegador moderno. Não há dependências, build ou rede obrigatória.

Este experimento testa **aparência, hierarquia e densidade**. Não valida movimento, timing, Correntes interativas, Fog of War dinâmico ou outras regras temporais; esses itens exigirão protótipos executáveis específicos antes da implementação final.

Documento do experimento: `docs/prototypes/VIS-001-hud-layout.md`.
