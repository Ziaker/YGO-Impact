# Protótipos executáveis

Este diretório receberá experimentos executáveis de comportamento e interface, especialmente HTML/TypeScript quando isso reduzir retrabalho.

A tecnologia usada aqui não obriga a tecnologia final do jogo. Resultados e aprovações correspondentes devem ser documentados em `docs/prototypes/`.

Não adicionar protótipos vazios: cada entrada deve responder a uma pergunta de design concreta e reproduzível.
