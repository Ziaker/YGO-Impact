## Decisão vigente

O autor aprovou simultaneamente:

- **A — Prisma de Retrato**
- **C — Lente de Combate**

## Contrato visual

O núcleo visual da unidade contém:

- arte;
- efeito;
- RACE com iconografia;
- Nível com iconografia;
- ELEM com iconografia;
- Keywords com iconografia.
