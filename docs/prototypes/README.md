# Registro de protótipos

Toda decisão visual relevante que ainda não esteja aprovada deve ser comparada em três opções: A, B e C.

Cada experimento deve registrar, no mínimo:

- identificador e data;
- objetivo, problema e hipótese;
- opções A/B/C e diferenças;
- cenário, dispositivo e resolução;
- controles e critérios;
- casos extremos relevantes;
- capturas, vídeos ou links executáveis;
- resultado e feedback;
- opção aprovada e responsável;
- impacto técnico e histórico de substituições.

Aparência pode usar protótipo estático. Interação, timing, movimento, animação, Correntes, Fog of War, densidade de informação e feedback exigem protótipo executável.

Nenhuma opção é considerada aprovada sem confirmação explícita do autor.
