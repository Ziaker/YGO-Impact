## YGOPRODeck API

`scripts/baixar_artes.py` consulta a API pública do YGOPRODeck para localizar dados de cartas e URLs do campo `image_url_cropped`.

O repositório registra no `manifest.json` a URL de origem usada para cada imagem coletada. O jogo não deve depender de hotlink durante a execução; as imagens selecionadas são obtidas previamente pela ferramenta de sincronização.

O uso da API e das imagens de terceiros não transfere propriedade sobre esse conteúdo ao projeto.
